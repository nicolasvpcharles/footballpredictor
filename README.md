# footballpredictor
a simple example football predictor using my c++ github module

I am using my module that you can find <a href="https://github.com/nicolasvpcharles/SAi">here</a> . <br>
For the API i am using <a href="www.football-data.org">football data's</a> api check it out

## Run the program



to run the program go on your computer and compile main.cpp it using g++

```` bash
g++ main.cpp -o main
````

then you should have a executable that you can launch
